## Per-platform notes
- Web: same Expo code via react-native-web. Existing GitHub Pages web app stays live until mobile reaches parity.
- Android: APK via EAS `preview` profile; AAB via `production`.
- iOS: needs an Apple Developer account (paid). Internal TestFlight / ad-hoc only through Apple's signing flow; an IPA cannot be sideloaded onto an arbitrary iPhone.
